Frequently asked questions

How do I add the widget?

Press and hold an empty area on your Android home screen, open the Widgets menu and choose Clash Timer Hub. Resize the widget to show more accounts.

How do I import my timers?

Copy a data export from the Clash of Clans settings and import it using the Clash Timer Hub sync button. The GitHub project has up-to-date instructions.
