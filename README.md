# AshLab Studios

Portfolio voor Android-apps in HTML, CSS en JavaScript. Geen build of externe dependencies.

## Voorbeeld lokaal openen

Start vanuit deze map

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. De demo gebruikt fictieve timers.

## GitHub Pages

Ga naar Settings → Pages → Deploy from a branch. Kies `main` en `/ (root)`.

Projectadres na publicatie  
https://ashot978.github.io/AshLabStudios/

## Een app toevoegen

Voeg een eigen appmap onder `apps/` toe en plaats een kaart op de homepage. Gebruik `concepten/appbeleid.md` als invuldocument. Gebruik in Play Console de directe URL van het definitieve privacybeleid van de app, naast de vermelding in de app zelf.
